# Busker class 



## Subclasses


### Fortune Teller

roll 1d12 on a table

each possible roll gives your character a random fortune card.

Each card can be burned as an action or two actions (not sure which yet) to put a debuff or buff on a creature of your choice within 30 feet of you, each card has a different buff.

Possible re-shuffle mechanics>

Burned cards immediately return to deck to be used again.

Burned cards only return to deck on a short rest

Burned cards return to the deck only if you want them to, otherwise they return on a short rest.
