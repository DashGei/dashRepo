# Rest

Adventurers recover through rest, but not all rest is equal. The quality of a party's sleep, shelter, food, and company can determine how much they recover.

Whenever the party completes a period of rest, the party makes one **Rest Test**. The entire party shares the result.

## The Rest Test

A Rest Test uses a pool of dice rather than a single die. Roll all of the dice in the pool and add their results together. Compare the total to the Rest Test's **Difficulty Total (DT) of 7**.

| Degree       | Total | Rest          |
| ------------ | ----: | ------------- |
| **Miss**     |     0 | Poor Rest     |
| **Minor**    |     7 | Minor Rest    |
| **Moderate** |    14 | Moderate Rest |
| **Major**    |    21 | Major Rest    |
The entire party receives the same degree of Rest, unless a feature states otherwise. And a party which is unhappy with their rest must take the time to make a new Rest Test.

## Building the Rest Pool

The party rolls a number of dice determined by the number of hours the party is taking to rest.

| Time     | Dice |
| -------- | ---: |
| 1 hour   |    2 |
| 4 hours  |    3 |
| 7 hours  |    4 |
| 10 hours |    5 |
| 13 hours |    6 |
| 16 hours |    7 |

The quality of the party's resting place determines the size of each Time Die.

| Quality   | Time Die | Example     |
| --------- | -------: | ----------- |
| **Awful** |       d2 | Sewers      |
| **Poor**  |       d4 | Undergrowth |
| **Fine**  |       d6 | Bedroll     |
| **Nice**  |       d8 | Cot         |
| **Good**  |      d10 | Made bed    |
| **Great** |      d12 | Fancy room  |
So resting for 7 hours in a mediocre inn (Nice) will allow the party to add 4d8 to the rest pool.

## Rest Quality

The degree of the Rest Test determines how much the party recovers.

| Rest       | Effect                                                      |
| ---------- | ----------------------------------------------------------- |
| Miss       | Restore All Stamina, 1 Strain, 1 Mental                     |
| Minor      | Restore all Stamina, Flesh, 5 Strain, 2 Mental              |
| Moderate   | Restore all Stamina, Flesh, 10 Strain, 5 Mental, 2 Vitality |
| Major Rest | Restore all Hit Points and Strain                           |
## Recreation

After a party has rested for at least **4 hours**, its members may spend their remaining time on **Downtime Activities**.

Below are the common activities completable by anyone, but some characters may gain access to features which allow them to make new downtime activities instead.

### Cook

No more than one character proficient with Cooking Tools may serve as the party's **Cook**, provided they have suitable ingredients and a place to prepare food.

The Cook makes a **DT 5 Threshold Test** using their Mental modifier. Add a die to the Rest Pool based on the result.

| Result       | Rest Die |
| ------------ | -------- |
| **Miss**     | -        |
| **Minor**    | d2       |
| **Moderate** | d4       |
| **Major**    | d6       |

### Director

A character proficient in **Performance** or **Persuasion** may serve as the party's **Director**.

The Director makes a **DT 5 Threshold Test** using their Mental modifier. Add a die to the Rest Pool based on the result.

| Result       | Rest Die |
| ------------ | -------- |
| **Miss**     | -        |
| **Minor**    | d2       |
| **Moderate** | d4       |
| **Major**    | d6       |

A Director might entertain the party with music, stories, games, speeches, or conversation.

### Crafting

A character may spend downtime crafting an item, repairing equipment, or working on another project. Use the appropriate crafting rules.

### Mentorship

A character may serve as a **Mentor** and teach one lesson to a **Student**. Use the Mentorship rules.

### Praying

A character may spend downtime in prayer to a chosen god. If they did not receive Divine Favor from that god on the previous day, the party gains **1 Divine Favor** with that god.
